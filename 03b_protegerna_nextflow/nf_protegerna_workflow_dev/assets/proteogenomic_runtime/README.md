# Bundled reconstruction source

Generated by `scripts/build_runtime.py` from the sibling `code_proteogenomic_database_v7`
directory. Every bundled module is an unmodified copy; `SOURCE_MANIFEST.json` lists their
SHA-256 hashes and the source modules left out because the pipeline never imports them.
Defaults in `../resolved_publication_defaults.json` are the parser defaults overlaid with
`../workflow.publication.v5.toml`; the same script regenerates `../params.publication.yml`.

Pipeline-owned file (not part of the standalone source): `nextflow_adapter.py`. Each
process runs `python3 -B runtime/nextflow_adapter.py <stage>` with a base64 JSON payload on
standard input. The adapter stages samplesheet metadata, builds the program's argument
list, runs it, and records `task_inputs.json`, `command.json` and `versions.yml`.
